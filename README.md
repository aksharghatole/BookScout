# BookScout

BookScout helps you find a book, compare places to buy it, and look for free ways to read it. Save titles you’re interested in and keep your list in your browser.

There’s no account or API key. Searches go to book catalogs and reading providers; BookScout doesn’t host books. Prices and access can change, so check the edition, rights, and final price on the provider’s page.

### Try it locally

From this folder, run:

```sh
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). Run the automated checks with `node --test` (Node 20 or newer).

For the full list of sources, features, and limitations, see the [project reference](README-REFERENCE.md).
